# Formato básico de los scripts
Este documento contiene el formato básico de los scripts .sl


Reglas del formato

* Los scripts deben guardarse con la extensión .sl.
* Cada línea contiene un único comando.
* Los comandos del lenguaje se escriben en minúsculas (set, copy, run, log).
* Los valores de texto se escriben entre comillas dobles "...".
* Los comentarios inician con #
* Las variables se declaran con set y pueden usarse con "$variable".
* Los bloques van dentro de {}
